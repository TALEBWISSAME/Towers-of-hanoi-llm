# Analyse personnelle — TP3 No-code & Low-code

Pendant ce TP, j'ai utilisé GitHub Copilot pour m'aider à développer le jeu des Tours de Hanoï.

L'IA m'a permis de gagner du temps pour créer la structure HTML, le style CSS et les fonctions JavaScript.

J'ai appris à formuler des prompts plus précis pour obtenir le résultat attendu.

Cependant, les réponses générées n'étaient pas toujours parfaites et j'ai dû vérifier le code.

Par exemple, un commentaire JSDoc sur la détection de victoire ne décrivait pas correctement le comportement de la fonction.

J'ai aussi dû comprendre moi-même le fonctionnement de l'algorithme récursif et les règles des déplacements.

La comparaison entre Copilot et Claude m'a montré qu'un même prompt peut produire des codes différents.

Les tests automatiques m'ont aidée à vérifier le fonctionnement des fonctions principales.

Si je devais refaire ce TP, je testerais chaque fonctionnalité dès sa création et je vérifierais plus attentivement les réponses de l'IA.

Ce travail m'a permis de mieux comprendre l'intérêt des LLM, mais aussi l'importance de ne pas utiliser leur code sans le vérifier.
